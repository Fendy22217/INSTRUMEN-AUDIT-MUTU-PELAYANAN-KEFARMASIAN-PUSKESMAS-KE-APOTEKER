APLIKASI AUDIT MUTU PELAYANAN KEFARMASIAN PUSKESMAS (OFFLINE)
Versi 1.1 — Tema Hijau dan Emas
Identitas aplikasi: apt. Fendy Prasetyawan, S.Farm., M.Farm.

ISI
- index.html: aplikasi utama
- README.txt: petunjuk penggunaan

CARA MENJALANKAN
1. Ekstrak ZIP.
2. Buka file index.html menggunakan Chrome, Edge, Firefox, atau browser modern.
3. Tidak perlu internet, instalasi, akun, atau server.
4. Data tersimpan lokal pada browser/perangkat yang sama.
5. Gunakan tombol Cadangkan data (JSON) secara berkala.
6. Untuk memindahkan data, ekspor JSON dari perangkat lama lalu pulihkan pada perangkat baru.

FITUR
- 73 indikator dari 8 dimensi sesuai instrumen yang diberikan.
- Skor 2, 1, 0, dan NA.
- Identitas audit Puskesmas.
- Keterangan bukti aktual/temuan per indikator.
- Rekap per dimensi dan total.
- Perhitungan capaian dengan NA dan indikator kosong dipisahkan.
- Kategori awal dapat diubah.
- Daftar indikator skor 0/1 untuk tindak lanjut.
- Kolom prioritas, rencana perbaikan, penanggung jawab, dan target.
- Ekspor CSV untuk skor, rekap, dan prioritas.
- Cadangan/pemulihan JSON.
- Cetak atau simpan hasil ke PDF melalui menu cetak browser.

PENTING: SKOR DAN KATEGORI
Skala 0-2 dan arti NA mengikuti dokumen sumber.
Kategori default:
- Baik >=80%
- Cukup >=60% dan <80%
- Perlu perbaikan <60%
Kategori tersebut adalah rekomendasi metodologis awal, bukan kategori yang tercantum pada dokumen sumber dan bukan otomatis standar regulasi. Silakan sepakati/validasi sebelum digunakan resmi atau sebagai penelitian.
Skor 0 disaring sebagai prioritas awal Tinggi dan skor 1 sebagai Sedang. Auditor dapat mengubah tingkat prioritas sesuai risiko, dampak, dan konteks. Penyaring ini bukan penilaian risiko klinis tervalidasi.

PENGGUNAAN DATA
- Aplikasi tidak mengirim data ke internet/server.
- Data disimpan pada penyimpanan browser lokal. Membersihkan data browser dapat menghapus data aplikasi.
- Jangan memasukkan identitas pasien atau informasi sensitif yang tidak diperlukan.
- Simpan backup JSON di lokasi aman dan sesuai kebijakan institusi.
- Uji aplikasi terlebih dahulu dengan data uji, lalu hapus data uji sebelum audit resmi.

CATATAN INSTRUMEN
Indikator mengikuti dokumen yang diberikan. Aplikasi tidak menggantikan verifikasi regulasi, SOP, penilaian auditor, validasi instrumen, atau persetujuan institusi. Rekomendasi pengembangan instrumen ditandai di dalam aplikasi.
